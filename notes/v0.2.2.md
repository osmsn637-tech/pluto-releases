# Pluto CLI v0.2.2

This release prepares the CLI and runtime packages for the QEU control-plane
port without deploying or changing production state.

Highlights:

- completes the QEU control-plane client mutation flow and verifier polling;
- pins byte-identical release-v1, release-v2, Android candidate, iOS candidate,
  and trusted-verifier protocol fixtures;
- includes the guarded Android restart and Failure Lab evidence hardening;
- makes Android baseline publication atomic and durable under concurrent builds;
- makes exported iOS package tests independent of private monorepo TLS files;
- embeds private SDK commit
  `259e86aa4d951d7aa907c57299223a8397dcc265`; and
- keeps CLI self-update pointed at
  `osmsn637-tech/pluto-releases` with the existing release trust root.

Prepared targets:

- `darwin-arm64`
- `darwin-amd64`
- `linux-amd64`

Each archive contains only `pluto` and `THIRD_PARTY_NOTICES.txt`. Publish each
archive together with its matching `.sha256` and `.sig` files. The release must
not be published until the embedded SDK commit is reachable from the private
`qeuapp/pluto-sdk` repository.
