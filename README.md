# Pluto Releases

Public, signed Pluto CLI and engine-bundle artifacts. Product source is not published here.

Release assets are published through GitHub Releases rather than committed to
the repository. Every CLI archive has a `.sha256` checksum and an Ed25519
`.sig` signature over that checksum.

Current CLI release: `v0.3.1`


details.
